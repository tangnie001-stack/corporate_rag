# P3 词项命中探针（jieba + PG 全文检索 横向比较）

- 语料：176 个分块 / 5 个知识库
- 检索条数 k：30（= TOP_K_RETRIEVAL，上限 100）
- 探针词项数：30（n-gram 2..4，df ∈ [2, 0.1×N]）

> **仅供相对比较，不得作为质量基线或发布判据。**
> 176 分块、k=30 时单词项的命中集合可能已占语料 17%–28%，多数词项会**平凡通过**；
> 探针的用途是在同一语料上横向比配置。

## 分组 A：分词配置（固定打分算法 = BM25Okapi，字符级 vs 词项级）

| 配置 | 词项命中率 |
|---|---|
| char-bm25 | 1.0000 |
| jieba-bm25 | 0.9667 |
| jieba-tsrank | 0.5000 |
| pg-trgm | 0.9333 |

> 注：`jieba-tsrank` 的生产落地形态（存储侧依赖 `scripts/rewrite_content_seg.py` 的重写结果）；
> `pg-trgm` 是本地唯一可对照的扩展方案（`similarity()` 排序）。
