>
> 运行日志显示 6 题**全部** `contexts=0`
> （`[cli] question answer done index=N answer_len=… contexts=0`），RAGAS 收到的
> `retrieved_contexts` 全为空列表 → `context_precision` / `context_recall` 恒为 0、
> `faithfulness` 无法计算（nan）。
>
> **根因是 eval 链路缺陷，不是 P2 造成**：`agent_finalize` 只从
> `RequestContext.tool_contexts` 读上下文（`src/agents/graph/agent_node.py:310-316`），
> 而 `RequestContext` 仅由生产入口 `src/api/chat.py:80` 与 fork executor 设置
> （`src/agents/skills/executor.py:192`）；`src/cli/eval_ragas.py` 从不设置
> `current_request_ctx` → 检索工具把上下文追加进一个即弃的空列表
> （`src/agents/tools/rag_tools.py:223-229`）。该缺陷由 2026-09-12 的 RequestContext
> 重构引入，**早于 P2**；8 月历史报告（`retrieved_contexts` 非空，347–2061 字符）
> 产生于重构之前，故与本次不可比。
>
> 另有 3/6 题因 `[agent] iteration limit`（iteration=5 触顶）产出空答，
> 进一步压低 `answer_relevancy`。
