# Chat 页面（deepseek-harness 风格）

> 基于 deepseek-harness Web UI 重新设计（参考源码 `packages/client/ui-conversation`、`ui-layout`、`ui-workspace` 与页面截图）：**布局结构**参考（左侧会话栏 + 中间主区：新对话页居中输入框 / 历史对话页底部输入框），**视觉走浅色系（与现有 chat.html / MASTER.md 一致）**；**核心改动**是把"工作区（Workspace）选择器"对应为"知识库（KB）选择器"，置于**输入框上方独立一行**、单选可取消勾选，与项目从"Corporate RAG"转向"Corporate Agent Harness"的定位一致。

## 整体布局（参考 deepseek-harness `AppFrame` 三栏 grid 的简化版）

页面分**两个独立页面**（不是同一页内状态切换）：**新对话页**（创建会话，含知识库选择器）与**历史对话页**（会话已绑定 KB，输入框上方不再提供选择）。两者共用侧栏。

**KB 会话级绑定设计**：知识库在**新建会话时选择**，选定后该会话固定绑定该 KB，会话内不可改；要更换 KB 需新建会话重新选择。历史对话页顶栏以只读徽标展示该会话绑定的 KB。

│                             │  │ 输入区…                  [➤] │  │
│                             │  └────────────────────────────────┘  │
└─────────────────────────────┴──────────────────────────────────────┘

- **左侧栏（280px，浅色 #FFFFFF）**，自上而下：
  1. **头部**：Logo + 品牌名（Corporate Agent Harness）+ 版本号（v0.1.0）；无 Collapse 按钮
  2. **功能块**：两个功能按钮——新建会话（进入新对话页）、知识库管理（无其他导航）
  3. **会话历史**：会话列表（可滚动，项带相对时间，active/hover 态；点击进入历史对话页）
  4. **底部**：登录头像（点击弹登录/退出，用户名 + 状态文字）
- **新对话页**：整页居中——Logo + 品牌 + 预览徽标 + 主标题 + 副标题 + **居中输入框**（max-width 720px）；**无示例问题**
- **历史对话页**：**顶栏显示 `会话名 + 空格 + 知识库:XXX`**（KB 紫色区分；会话未选 KB 则不显示知识库部分）+ 预览徽标；消息流（可滚动）+ **底部固定输入框**（max-width 880px，**无 KB 选择器**）
- **输入框**：圆角 24px 白底卡片（#FFFFFF，描边 #E2E8F0）；仅含 KB 选择器 + 输入区 + 发送按钮

### 知识库选择器 ★（核心改动 · v4）

| 项 | 规格 |
| | |
| 位置 | **输入框上方独立一行**（`.kb-bar`），不嵌在输入框内；新对话页在副标题与输入框之间，历史对话页在消息流与输入框之间 |
| 形态 | 胶囊按钮：文件夹图标（Lucide `Folder` SVG）+ 当前 KB 名（选中主蓝 `#3B82F6`；未勾选显示"选择知识库"灰 `#64748B`）+ 下拉箭头 |
| 样式 | 白底胶囊（`bg #FFFFFF`，border `#E2E8F0`，hover border 主蓝 `#3B82F6`），圆角 10px，padding 7px 14px，文字 13px，轻阴影 |
| 弹窗 | 点击弹出（锚定胶囊下方，top 100%）：标题"选择知识库" + KB 列表 + 分隔线 + "知识库管理…"入口；空 KB 列表时直接显示"前往知识库管理" |
| 交互 | **单选勾选**：每项右侧圆形单选点（未选空心描边，选中蓝色填充 + 白勾）；点 A 选中同时取消 B；**再点当前项取消勾选**。**默认不勾选**，胶囊显示"选择知识库"；勾选后胶囊显示所选 KB 名；取消勾选后胶囊显示"请选择知识库"（不做"全部知识库"跨库语义，取消 = 未选择待用户重选） |
| 切换副作用 | 选中 KB 后：会话历史切换到该 KB 的会话、检索/搜索工具按该 KB 配置；未勾选（显示"请选择知识库"）时按未指定 KB 处理（由上层决定跨库或提示选择） |

### 发送按钮（deepseek-harness 样式）

| 项 | 规格 |
| | |
| 位置 | 输入框右下角 |
| 形态 | 圆形按钮（38×38，border-radius 50%），图标右上箭头（`ArrowUp`）；**默认透明底 + 描边 `#E2E8F0`；有内容时填充主蓝 `#3B82F6` + 白色图标**（deepseek-harness 发送按钮样式） |
| 状态 | 输入为空 → disabled（透明度 0.4）；有内容 → 蓝色填充可用；生成中 → 旋转图标 + "停止"语义 |

## 消息流（浅色，参照现有 chat.html）

- **用户气泡**：右对齐，**浅灰底 `#F1F5F9` 深字 `#1E293B`**，圆角右上 4px（去棱角），其余 12px；**不含时间戳**
- **AI 回复（markdown）**：左对齐，**浅灰底 `#F8FAFC` + 描边 `#E2E8F0`**（与现有 `--bubble-ai` 一致），markdown 排版（标题 h1-h3 / 列表 / 加粗 / 引用 / 代码块 / 表格）；**不含时间戳**
- **模型标注**：AI 回复末尾一行小字"由 **DeepSeek-V4-Flash** 回答"（11px muted；模型名 secondary），真实环境取当前轮 `model_used`
- **工具调用/检索状态**：AI 回复下方紧凑行（`bg #F1F5F9`，图标 + 文字，如"🔍 检索：腾讯控股年报（2 条）"）
- **引用（citations）**：AI 回复下方来源卡（`bg #F1F5F9`，蓝边 `#3B82F6`，`[1] 来源.pdf (p.3)` + 摘要片段）
- **反馈按钮**：AI 回复右下角 👍/👎
- **深度思考块**：AI 回复内可折叠的 reasoning 段（`bg #F1F5F9`，左蓝色边）

## 数据源（与本项目 API 对接）

| UI 元素 | 数据来源 |
| | |
| KB 选择器列表 | `GET /api/kb/list`（当前用户的知识库） |
| KB 切换副作用 | `POST /api/chat/stream` body 带 `kb_id`（已有）；会话列表按 kb_id 分组展示 |
| 会话列表 | `GET /api/sessions/list`（按 KB 分组需新增 `?kb_id=` 或客户端按 kb_id 分组） |
| 消息流 | SSE（`/api/chat/stream`，已有） |

## 与现有 chat-redesign 的差异

- 布局参考 deepseek-harness（左侧会话栏 + 双页面形态），**整体走浅色系**（与现有 chat.html / MASTER.md 一致，非深色）
- KB 选择器从"请求参数隐式选择"→ **输入框上方独立胶囊 + 单选弹窗**（对应 deepseek `Choose workspace` 语义，位置在输入框上方而非嵌入）
- 侧栏改为：头部（Logo+版本）/ 功能块（新建会话+知识库管理）/ 会话历史 / 底部登录头像
- **精简（v2 决策）**：去掉 Standard mode、Commands、Access mode、模型选择、右栏 Details、附件按钮；发送按钮改用 deepseek-harness 样式（透明描边 → 有内容时蓝色填充）
- 新增 KB 切换副作用：会话按 KB 分组显示
