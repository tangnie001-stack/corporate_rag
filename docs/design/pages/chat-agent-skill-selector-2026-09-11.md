# Chat 页：智能体选择器 + 技能选择器

> 归属 change：`docs/openspec/changes/session-agent-and-skill-invocation/`（capability `chat-harness-ui` / `agent-preset` / `skill-invocation`）。
> 基线沿用 `MASTER.md`（浅色 Swiss 极简）与 `pages/chat-harness.md`（新对话页居中 / 历史对话页底部固定）。本页只描述**两个新增选择器**，不改动既有布局与配色。
> 预览：`docs/design/chat-agent-skill-selector-mockup-2026-09-11.html`

## 一句话定位

| 选择器 | 回答的问题 | 粒度 | 生效范围 |
|--------|-----------|------|---------|
| 智能体 | **谁来做**（人设 / 执行者） | 会话级 | 会话内固定，不可更改 |
| 技能 | **按什么手册做**（方法论） | 消息级 | 触发后本会话持续生效 |

两者正交：智能体决定身份，技能决定打法；`/xxx` 只命名技能，与智能体无关。

## 整体布局（新对话页）

```
                 [Logo]
        Corporate Agent Harness  [预览版]
             探索企业知识，赋能业务问答
       基于工具与知识库的智能助手，支持多知识库切换与联网补充

   [📁 知识库：腾讯 ▼]  [👤 默认 ▼]     ← kb-bar 同一行，左对齐，gap 8px
   ┌────────────────────────────────────────┐
   │ 描述你想查询的内容…                      │
   │  [💡深度思考] [📖技能 ▼]         [➤]   │ ← composer-bottom 左侧两枚 chip
   └────────────────────────────────────────┘
```

- 两个选择器**同处** `kb-bar` 行：知识库在左，智能体紧邻其右（`gap: 8px`），行整体仍 `max-width: 720px` 居中。
- 技能选择器与「深度思考」chip **同处** `composer-bottom` 左侧；发送按钮仍在右侧（`margin-left: auto` 不变）。
- 历史对话页输入框**同样提供技能选择器**（消息级，无需不可变）；**不提供智能体选择器**（会话已固定），顶栏以只读徽标回显。

## 组件 ①：智能体选择器 agent-selector ★

### 触发胶囊（与 kb-trigger 同构）

| 项 | 规格 |
|----|------|
| 位置 | `kb-bar` 内、知识库胶囊**右侧** |
| 形态 | 胶囊按钮：人像图标（Lucide `user-round`，14px）+ 当前智能体名 + 下拉箭头（12px） |
| 样式 | 与 `.kb-trigger` **完全一致**：白底 `--surface`、1px `--border`、圆角 10px、padding 7px 14px、13px、轻阴影 `--shadow`；hover 边框变 `--primary` |
| 默认态 | 文案 **「默认」**，字色 `--text-secondary`、字重 400（对应未选中，即通用助手） |
| 选中态 | 显示智能体名，字色 `--primary`、字重 500 |
| 图标语义 | 人像 = 「谁在做」，与知识库的文件夹图标形成区分 |

> 默认项文案以 **「默认」** 为准（简洁）；「默认」即系统默认 system prompt / 通用助手，不新造 prompt。

### 下拉菜单（向上不弹，向下弹）

| 项 | 规格 |
|----|------|
| 锚点 | 胶囊下方 `top: calc(100% + 6px)`、左对齐；沿用 `.kb-menu` 样式（12px 圆角、`--shadow-lg`、`z-index: 30`） |
| 宽度 | `min-width: 300px`（比 KB 菜单宽，容纳描述文字） |
| 标题 | 「选择智能体」（11px、`--text-muted`、大写字母间距） |
| 列表项 | 左侧人像图标 + 名称（13px `--text`）+ 描述（12px `--text-secondary`，单行截断）；右侧圆形单选点（未选空心 / 选中 `--primary` 填充 + 白勾） |
| 默认项 | 固定排在首位，名称「默认」，描述「通用助手」 |
| 空目录 | `agents/` 缺失或为空时仅列出「默认」项，不报错 |
| 底部注脚 | 分隔线 + 11px `--text-muted` 提示：**「选定后本会话内不可更改」**（对应不可变约束的可发现性） |
| 交互 | 单选：点 A 选中并取消 B；**再点当前项不取消**（智能体不允许回到"未选中间态"，因为已开始会话无法更换） |
| 选中副作用 | 仅作用于**本次会话**；会话开始后选择器转为锁定态 |

### 锁定态（历史对话页）

历史会话已绑定智能体，选择器**不可交互**：

- 顶栏回显：`会话名 + 知识库:XXX + 智能体:财务专家`（智能体部分用 `--primary` 区分，未选定则不显示）。
- 输入区不渲染智能体胶囊；如需更换只能新建对话。

## 组件 ②：技能选择器 skill-selector ★

### 触发 chip（与 thinking-chip 同构）

| 项 | 规格 |
|----|------|
| 位置 | `composer-bottom` 左侧，「深度思考」chip 的**右侧**，与左侧组 `gap: 10px`（沿用 `.composer-bottom` 既有间距，不新增容器） |
| 形态 | 紧凑 chip：手册图标（Lucide `book-open`，13px）+ 文案 + 下拉箭头（10px） |
| 样式 | 与 `.thinking-chip` **完全一致**：高 28px、padding 0 12px、圆角 14px、透明底、12px 字重 500、色 `--text-secondary`；hover 底变 `--bg` |
| 空闲态 | 文案 **「技能」** |
| 激活态 | 文案显示技能名（如「技能 · 财报分析手册」），样式同 `.thinking-chip.active`：`--primary-light` 底 + `--primary` 描边 + `--primary` 字；再次点击可换 |
| 无技能时 | chip 仍可点击，菜单展示"暂无可调用技能"（不隐藏 chip，避免布局跳动） |

### 下拉菜单（向上弹出）

| 项 | 规格 |
|----|------|
| 锚点 | 因 composer 位于页面底部，菜单**向上弹出**：`bottom: calc(100% + 8px)`、左对齐 |
| 宽度 | `min-width: 300px`，`max-height: 320px` 可滚动 |
| 标题 | 「选择技能」 |
| 列表项 | 左侧手册图标 + 技能名（13px，等宽字体显示 `/name` 中的 name）+ 描述（12px 单行截断）+ 右侧单选点 |
| 首项 | **「不使用技能」**（清除当前选择，圆点为空心） |
| 过滤 | **只列 `user-invocable ≠ false` 的技能**（双轴控制的前端侧） |
| 底部注脚 | 11px 提示：**「插入 /名称 后发送，本会话持续生效」** |
| 交互 | 单选。选中后**向输入框行首插入 `/name␣` 字面量**（光标置于名称之后），与手输 `/` 完全等价；输入框已有内容时插入到最前并补一个空格 |
| 与 `/` 补全的关系 | 同一份候选数据、同一套后端解析。chip 是**可发现性入口**，输入框行首 `/` 补全是**键盘快捷入口**，二者互不冲突 |

## 数据源

| UI 元素 | 数据来源 |
|---------|---------|
| 智能体候选 | `GET /api/agents`（读 `agents/catalog.json`） |
| 技能候选 | `GET /api/skills`（读 `skills/catalog.json`，已过滤不可用户调用项） |
| 会话绑定 | `POST /api/chat/stream` body 带 `agent`；会话已绑且传不同值 → **服务端忽略 + warning（无 400）** |
| 顶栏回显 | `POST /api/sessions/list` 每项 `agent` 字段（恢复会话时回显）+ 流事件 `agent_used` 静默纠正不一致 |

## 状态矩阵

| 场景 | 智能体选择器 | 技能选择器 |
|------|-------------|-----------|
| 新对话页 · 初始 | 「默认」灰字，可点 | 「技能」灰字，可点 |
| 新对话页 · 已选智能体 | 蓝色智能体名，可改（会话未开始） | — |
| 新对话页 · 已选技能 | — | 蓝底 + 技能名 |
| 历史对话页 | 不渲染（顶栏只读徽标回显） | 正常可用（消息级，不限会话） |
| `agents/` 目录缺失 | 仅「默认」一项 | — |
| 无 `user-invocable` 技能 | — | chip 可点，菜单显示空态 |

## 无障碍与交互规范

- 触发胶囊：`role="button"`、`aria-haspopup="listbox"`、`aria-expanded` 随开合切换、`tabindex="0"`。
- 菜单：`role="listbox"`，项 `role="option"` + `aria-selected`；沿用 KB 菜单既有实现模式。
- 键盘：Enter/Space 开合；↑/↓ 移动高亮，Enter 选中，Esc 关闭；焦点归还触发胶囊。
- 焦点可见：`box-shadow: 0 0 0 3px rgba(59,130,246,0.3)`（复用 thinking-chip 的 focus-visible 规格）。
- 点击外部 / 遮罩关闭；两个菜单与引用抽屉、任务面板**互斥单开**。
- 过渡 150ms；`prefers-reduced-motion` 下取消动画。
- 图标一律内联 SVG（Lucide），不使用 emoji。
- 响应式：`kb-bar` 与 `composer` 在 < 720px 时随容器收缩，选择器胶囊不换行（必要时名称省略号截断）。

## 明确不做（v1）

- 智能体选择器**不做搜索框**（选项控制在 5-8 个）。
- 技能选择器**不做多选**（一次消息一个主技能，多个技能靠 `/` 连写或后续设计）。
- 两个选择器**不合并**（智能体走会话级、技能走消息级，语义不同）。
- 不展示 `model`（本项目模型不可选）。

## 验收 / 验证

- 用 `playwright-cli` 打开 `http://localhost/`（登录后进入 `chat.html`）核对：
  - **智能体选择器落位**：新对话页 `kb-bar` 内、知识库胶囊**右侧**；默认项文案「默认」灰字
  - **技能选择器落位**：两个 composer 的「深度思考」chip **右侧**；空闲文案「技能」灰字
  - **弹向**：智能体菜单**向下**弹出（`top: calc(100% + 6px)`）、技能菜单**向上**弹出（`bottom: calc(100% + 8px)`）、行首 `/` 补全菜单**向下**弹出
  - **插入字面量**：选中技能后向输入框行首插入 `/name␣`（光标置于名称之后）；再选「不使用技能」剥除行首前缀
  - **顶栏回显**：历史对话页顶栏显示 `会话名 知识库:XXX 智能体:财务专家`（智能体段用 `--primary` 区分，未选定不显示）
  - **375px 不换行**：`kb-bar` 与 composer 在 375px 视口下选择器胶囊不换行
  - **键盘与互斥**：Enter/Space 开合、↑/↓ 移动高亮、Enter 选中、Esc 关闭、焦点归还触发胶囊；两个菜单与引用抽屉、任务面板互斥单开
- **端到端冒烟（真实后端）**：
  1. 智能体：选「财务专家」→ 发消息 → 断言顶栏智能体回显 + 请求体 `agent`
  2. 技能：chip 选技能（若 `/api/skills` 暂无候选则手输 `/financial-statement-analyzer 任务`）验证补全与插入
  3. 常规回归：不选智能体/技能发普通提问 → token 流式、citation、done 正常
  - `playwright-cli console` 断言无新增 error
