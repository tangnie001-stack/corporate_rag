智能体选择器（会话级）

  • 位置：知识库胶囊右侧，同一行 gap 8px
  • 默认项文案：「默认」（通用助手），灰字
  • 选中后蓝字；会话内不可更改，菜单底部有锁提示
  • 历史对话页不渲染，顶栏以只读徽标回显
  • 数据源：GET /api/agents

技能选择器（消息级）

  • 位置：深度思考 chip 右侧，同构 chip
  • 选中后 chip 变蓝并显示技能名
  • 选中 → 输入框行首插入 /name （与手输 / 等价）
  • 只列 user-invocable ≠ false 的技能
  • 数据源：GET /api/skills；菜单向上弹出

交互与无障碍

  • 触发元素 aria-haspopup="listbox" + aria-expanded
  • 键盘：↑/↓ 移动、Enter 选中、Esc 关闭并归还焦点
  • 焦点环 3px rgba(59,130,246,0.3)
  • 两菜单与引用抽屉 / 任务面板互斥单开
  • 过渡 150ms；尊重 prefers-reduced-motion
