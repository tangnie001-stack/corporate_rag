涵盖：深度思考开关 / 追问卡片 composer / abstention 转人工 / 答案反馈 / 模型信息 / 状态标签 / 引用卡片

设计原则：沿用现有 Minimalism & Swiss 风格（primary #3B82F6 / accent #F97316 / 720px 布局 / Lexend + Source Sans 3）。 交互统一 150ms 过渡、所有可点击元素 cursor:pointer、悬停有视觉反馈（边框/底色变化）、控件支持键盘焦点环（:focus-visible）。
整体对话界面 主视图

交互：hover 显示说明 tooltip；键盘可聚焦（:focus-visible 焦点环）；动画 150ms 平移。
